# Loan Default Prediction Using Logistic Regression and Tree-Based Models

## Project Overview

This project focuses on predicting potential loan defaults using machine learning techniques. It uses historical loan data to explore patterns associated with loan repayment and identify borrowers who may be at risk of default.

## Objectives

* Analyze loan-related data to identify patterns associated with loan defaults.
* Perform data preprocessing and feature engineering.
* Develop classification models to predict loan repayment outcomes.
* Evaluate model performance using appropriate classification metrics.
* Explore how machine learning can support financial risk assessment.

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Scikit-learn
* Matplotlib and Seaborn, if used in the notebook

## Machine Learning Models

* Logistic Regression
* Tree-based classification models implemented in the notebook

## Dataset

The project uses the LendingClub loan dataset, identified in the notebook as `accepted_2007_to_2018Q4.csv`.

The dataset contains historical loan records and is approximately 374 MB in the local project folder. It is not included in this GitHub repository because of its large size.

To run the notebook, obtain the dataset from its original source, place the CSV file in the same directory as the notebook, and ensure that its filename matches the name expected by the code.

## Project Workflow

1. Load the loan dataset.
2. Explore and analyze the data.
3. Clean and preprocess the data.
4. Prepare features and the target variable.
5. Train the classification models.
6. Evaluate model performance.
7. Analyze the results.

## How to Run

1. Install Python and Jupyter Notebook.
2. Install the required Python libraries used in the notebook.
3. Obtain the dataset and place it beside the notebook.
4. Open `LOAN DEFAULT PREDICTION.ipynb` in Jupyter Notebook or VS Code.
5. Run the notebook cells in order.

## Note

This project is intended for educational purposes and demonstrates the application of machine learning to loan default prediction. Model performance and conclusions should be interpreted based on the actual experimental results.
